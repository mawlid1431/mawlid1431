## 🔐 Security

<p align="center">
<img src="https://img.shields.io/badge/Arcjet-1A1A2E?style=for-the-badge" alt="Arcjet"/>
<img src="https://img.shields.io/badge/Clerk-6C47FF?style=for-the-badge&logo=clerk&logoColor=white" alt="Clerk"/>
<img src="https://img.shields.io/badge/JWT-000000?style=for-the-badge&logo=jsonwebtokens&logoColor=white" alt="JWT"/>
<img src="https://img.shields.io/badge/OAuth%202.0-3C873A?style=for-the-badge" alt="OAuth 2.0"/>
<img src="https://img.shields.io/badge/OWASP%20Top%2010-000000?style=for-the-badge&logo=owasp&logoColor=white" alt="OWASP Top 10"/>
<img src="https://img.shields.io/badge/Zod-3E67B1?style=for-the-badge&logo=zod&logoColor=white" alt="Zod"/>
<img src="https://img.shields.io/badge/Dependabot-025E8C?style=for-the-badge&logo=dependabot&logoColor=white" alt="Dependabot"/>
<img src="https://img.shields.io/badge/Cloudflare%20WAF-F38020?style=for-the-badge&logo=cloudflare&logoColor=white" alt="Cloudflare WAF"/>
<img src="https://img.shields.io/badge/Let's%20Encrypt-003A70?style=for-the-badge&logo=letsencrypt&logoColor=white" alt="Let's Encrypt"/>
</p>

- 🛡️ **App protection:** bot detection, rate limiting, email validation and attack shielding with **Arcjet**
- 🔑 **Auth:** Clerk, JWT and OAuth 2.0 with role-based access control and organization-scoped data
- 🏢 **Multi-tenant isolation:** every query and mutation verifies the record belongs to the caller's organization
- ✅ **Input validation:** server-side checks with Zod; never trusting client-sent sizes, IDs or roles
- 🔏 **Webhooks and secrets:** signature verification (Svix), secrets kept in environment variables, never in code
- 📦 **Supply chain:** Dependabot alerts and dependency audits, following the **OWASP Top 10**
